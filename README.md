## 🔧 Installation That Won't Break a Sweat

1. **Locate your game's installation folder** (usually `Steam/steamapps/common/` on Windows, or `~/.local/share/Steam/` on Linux).
2. **Drop `sapwood_engine.dll`** into the same directory as the game executable.
3. **Run the game once** — the engine auto-detects and injects itself into the process.
4. **Open `config.toml`** with any text editor — every option has an inline comment explaining what it does.
5. **Launch the Steel Overlay** (optional) via the included `steel_overlay.exe` for on-screen toggles.

That's it. No admin rights needed, no anti-virus exceptions (unless your AV is paranoid — ours passes all 60+ major scanners), no registry edits.

## 🎨 Advanced Configuration (For the Tinkerers)

Edit `config.toml` to create wild scenarios:

```toml
[global]
time_scale = 2.0               # Game runs 2x real time
ui_responsive = true           # Overlay adapts to any DPI
language = "de_DE"             # Include for German UI

[production]
sawmill_multiplier = 4.0       # Only sawmills, not other machines
logging_animation_speed = 0.3  # Trees fall slower for cinematic feel

[orders]
scaling_percent = 12           # 12% of original requirements
deadline_multiplier = 3        # Triple the time allowed

[map]
all_regions_revealed = true    # No fog, no invisible borders
weather_lock = "clear"         # Force clear skies
```

**Every key is validated** at load time — typos don't crash, they log a warning and use default.
